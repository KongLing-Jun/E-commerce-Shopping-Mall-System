# 端到端测试用例（人工验收）

## 用例 1：前台浏览到支付
1. 登录普通用户（`user/123456`）
2. 首页点击任一商品进入详情
3. 加入购物车并进入购物车页
4. 选择地址并提交订单
5. 支付订单（模拟）
6. 验证订单状态从“待支付”变为“待发货”

## 用例 2：后台发货
1. 登录管理员（`admin/123456`）
2. 进入后台订单列表
3. 对“待发货”订单执行发货
4. 填写物流单号（可选）
5. 验证订单状态为“已发货”

## 用例 3：用户确认收货
1. 普通用户进入订单列表
2. 找到“已发货”订单
3. 点击确认收货
4. 验证状态为“已完成”
