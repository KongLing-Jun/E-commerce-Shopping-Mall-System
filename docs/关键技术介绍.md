# 关键技术详细介绍（3C电子商城平台）

## 1. 前后端分离与 REST API
前后端分离通过“前端负责展示与交互、后端负责业务与数据”的方式降低耦合，便于各自独立开发与部署。后端统一提供 REST API，前端以标准 HTTP 请求调用，数据以 JSON 返回，形成清晰的数据契约。该模式有利于扩展多端（Web、移动端、小程序）并行开发，同时提升系统可维护性。

## 2. 前端技术栈

### 2.1 Vue 3
Vue 3 是项目的核心前端框架，采用组合式 API（Composition API）。它带来更清晰的逻辑组织方式，便于将数据状态、请求逻辑、事件处理等拆分成可复用的片段。Vue 的响应式系统保证 UI 与数据同步，提升用户交互体验。

### 2.2 Vue Router
Vue Router 用于前端路由管理，实现多页面体验的单页应用（SPA）。在本项目中：
- 通过路由守卫实现登录校验。
- 支持动态路由加载，实现后台菜单的权限控制。
- 路由参数用于商品详情、支付页面、订单查询等功能。

### 2.3 Pinia
Pinia 是 Vue 3 官方推荐的状态管理库。在项目中用于集中管理登录状态、用户信息、主题偏好等全局状态。相比传统的状态管理方式，Pinia 更轻量、语法更简洁，支持模块化与类型推导。

### 2.4 Axios
Axios 用于 HTTP 请求管理，统一封装请求头、异常处理和响应拦截。项目中常用做法包括：
- 请求拦截器自动携带 JWT Token。
- 响应拦截器处理错误码与登录失效提示。
- 统一的请求封装提升接口调用一致性。

### 2.5 Element Plus
Element Plus 是 Vue 3 的主流组件库，提供表格、表单、弹窗、分页等丰富组件。本项目后台管理界面依赖大量表格和表单组件，Element Plus 使其快速搭建，同时保证交互体验和一致的视觉风格。

### 2.6 TailwindCSS
TailwindCSS 是原子化 CSS 框架，提供大量预设样式类。项目利用 TailwindCSS 进行快速布局与响应式适配，避免频繁编写自定义 CSS，提高前端开发效率与界面可维护性。

## 3. 后端技术栈

### 3.1 Spring Boot 3.x
Spring Boot 提供快速构建项目的能力，内置自动配置机制，简化依赖管理与环境配置。通过 Spring Boot，项目能够快速集成 Web、Security、Data 等模块，并统一管理启动入口与配置文件。

### 3.2 Spring MVC
Spring MVC 负责 Web 层请求分发与控制器逻辑。项目采用 REST 风格接口设计：
- `@RestController` 提供标准 JSON 输出。
- `@RequestMapping` 等注解定义接口路由。
- 结合 `@RequestParam`、`@PathVariable` 实现参数传递。

### 3.3 Spring Security
Spring Security 是后端安全控制核心。项目使用它实现：
- 登录认证与访问控制。
- 角色与权限校验（RBAC）。
- 401/403 统一拦截与错误响应。

### 3.4 JWT（JSON Web Token）
JWT 是无状态认证机制。用户登录成功后生成 Token，前端保存并在请求头中携带。后端解析 Token 识别身份与角色，从而实现分布式场景下的轻量认证。

### 3.5 MyBatis-Plus
MyBatis-Plus 提供增强型 ORM 能力，支持：
- 通用 CRUD 操作，无需编写重复 SQL。
- 分页插件，简化分页查询。
- LambdaQueryWrapper 提升查询表达力与安全性。

### 3.6 MySQL
MySQL 是项目的核心数据存储。主要负责商品、订单、用户、角色、菜单等业务数据持久化。通过合理设计表结构与索引，保证查询性能与数据一致性。

### 3.7 Redis
Redis 用作缓存层，提升系统性能。项目中主要用途：
- 缓存首页推荐、商品详情等高频查询数据。
- 存储登录失败次数，防止暴力破解。
- 缓存 Token 黑名单，实现登出失效。

### 3.8 事务管理
订单创建、扣库存、写订单明细属于高一致性操作。项目利用 Spring 的事务机制确保这些操作要么全部成功，要么全部回滚，避免数据不一致。

### 3.9 RBAC 权限模型
RBAC（Role-Based Access Control）通过“用户—角色—权限”三层结构实现访问控制：
- 菜单与按钮权限统一配置。
- 后端 API 以权限码校验访问。
- 前端按权限动态渲染菜单与按钮。

## 4. 业务与辅助技术

### 4.1 Apache POI（Excel 导出）
后台订单数据支持导出 Excel，使用 Apache POI 生成 `.xlsx` 文件。管理员可对订单进行离线分析与归档。

### 4.2 Jsoup（XSS 清洗）
商品详情支持富文本输入，项目通过 Jsoup 进行 HTML 清洗，防止恶意脚本注入，提升安全性。

### 4.3 文件上传与白名单校验
后台支持图片上传，用于商品封面与轮播图。系统对上传类型进行白名单校验，避免非法文件上传风险。

## 5. 运维与测试技术

### 5.1 Docker Compose
Docker Compose 用于一键启动 MySQL、Redis、后端、前端、Nginx 等服务，保证开发与部署环境一致，降低环境配置成本。

### 5.2 Nginx
Nginx 作为反向代理与静态资源服务器，负责：
- 前端资源分发。
- 后端接口代理。
- TLS/HTTPS 终止，提高访问安全性。

### 5.3 Swagger/OpenAPI
Swagger 自动生成接口文档，便于前后端联调与接口测试。通过可视化界面直接调试 API，提升开发效率。

### 5.4 Postman/Newman
Postman 用于接口调试与手工验证。Newman 支持批量执行 Postman Collection，实现接口的自动化回归测试。

### 5.5 Jenkins
Jenkins 用于持续集成与自动化构建。通过流水线脚本，实现代码提交后的自动构建与部署，提高交付效率。
