# **摘 要**

随着电子商务和移动互联网的快速发展，3C电子产品因更新速度快、参数维度多、价格敏感度高，逐渐成为网络零售中最具代表性的商品类型之一。传统线下销售在商品展示范围、信息透明度和服务效率方面已难以满足用户需求，因此设计一个面向3C品类、具备完整交易闭环和后台精细化管理能力的电子购物商城，既具有现实应用价值，也具有较强的教学实践意义。本文以“基于Spring Boot + Vue的3C电子购物商城 ”为研究对象，围绕前后端分离架构下的商品展示、购物车、订单处理和后台管理等核心问题展开研究。

在系统实现过程中，后端采用Spring Boot构建RESTful服务，结合Spring Security、JWT与RBAC实现身份认证和权限控制；前端采用Vue与Element UI构建单页应用，完成首页展示、分类检索、商品详情、购物车和订单追踪等交互功能；数据层使用MySQL存储业务数据相关数据，利用MyBatis-Plus完成对象映射，同时，系统针对订单创建、库存扣减、购物车清理等关键场景设计事务控制与状态流转机制，保证业务一致性和操作安全性。

研究结果表明，该系统能够较好地满足3C电子购物商城的基本业务需求，形成“浏览—加购—下单—支付—发货—收货”的完整闭环，并支持管理员对用户、菜单、商品、轮播图、订单和统计报表进行统一管理。本文的研究为中小型垂直电商系统的设计与实现提供了可复用的思路，也为开展Java Web全栈项目开发、系统分析与论文写作提供了实践参考。

**关键词**：Spring Boot；Vue；3C电子商城；RBAC；MySQL

**Abstract**

With the rapid growth of e-commerce and mobile Internet, 3C products have become one of the most representative categories in online retail because of their fast iteration, complex specifications, and strong price sensitivity. Traditional offline sales can no longer fully satisfy users in terms of information transparency, product comparison, and transaction efficiency. Therefore, it is meaningful to design a 3C shopping mall system with a complete transaction loop and refined back-office management capability.

This thesis focuses on the design and implementation of a 3C electronics shopping mall based on Spring Boot and Vue. 

   During system implementation, the backend utilizes Spring Boot to build RESTful services, integrating Spring Security, JWT, and RBAC for identity authentication and permission control. The frontend employs Vue and Element UI to construct a single-page application, delivering interactive features such as homepage display, category search, product details, shopping cart, and order tracking. The data layer utilizes MySQL for business data storage, employing MyBatis-Plus for object mapping. Additionally, the system implements transaction control and state transition mechanisms for critical scenarios like order creation, inventory deduction, and cart clearing, ensuring business consistency and operational security.

The result shows that the system can support the complete business loop of browsing, cart management, order creation, mock payment, shipping, and receipt confirmation. It also supports unified administration of users, menus, products, banners, orders, and reports. The research provides a practical reference for the design of small and medium-sized vertical e-commerce systems and for full-stack software engineering education.

**Keywords:** Spring Boot; Vue; 3C shopping mall; RBAC; MySQL

# 第1章 绪论

总体来看，现有研究已经为商城系统的开发提供了较为成熟的技术路线和理论支持，但对于本科毕业设计而言，更重要的是在有限时间和合理范围内完成一个结构清晰、功能较完整、技术实现规范的系统。尤其是面向3C电子产品这一特定品类，系统在商品分类管理、参数展示、库存处理和订单流转等方面具有一定的针对性。因此，本文将在借鉴已有研究成果的基础上，结合3C电子产品销售的业务特点，完成一个具备基本的购物商城系统设计与实现。

本文的主要研究内容包括以下几个方面：

### （1）系统需求分析

在系统开发前，首先对3C电子购物商城的业务需求进行了分析。结合3C电子产品种类多、参数复杂、更新速度快等特点，对系统用户角色、功能模块和业务流程进行了梳理，明确了系统主要分为前台用户端和后台管理端两个部分。前台用户端主要面向普通消费者，重点满足用户注册登录、商品浏览、商品检索、购物车管理、订单提交和订单查询等需求；后台管理端主要面向管理员，重点实现商品管理、订单管理、用户管理和权限管理等功能。通过需求分析，为后续系统设计和实现奠定了基础。

### （2）系统总体架构设计

在明确需求的基础上，论文对系统总体架构进行了设计。系统采用前后端分离的开发模式，前端基于Vue构建用户交互界面，后端基于Spring Boot提供RESTful接口服务，数据库采用MySQL进行业务数据存储。系统整体按照分层思想进行设计，将前端表现层、后端控制层、业务逻辑层和数据访问层进行合理划分，使各模块职责明确、耦合度较低，从而提高系统的可维护性和扩展性。与此同时，系统还结合实际开发需求，对接口交互方式、模块划分和运行流程进行了统一规划。

论文围绕3C电子购物商城的核心业务功能，完成了多个功能模块的设计与实现。在用户端，主要实现了用户注册与登录、首页商品展示、商品分类浏览、商品搜索、商品详情查看、购物车管理、订单生成与订单查询等功能，使用户能够完成从商品浏览到下单购买的完整购物流程。在后台管理端，主要实现了用户管理、商品管理、轮播图管理、订单管理和菜单权限管理等功能，以支持管理员对商城系统进行统一维护和运营管理。通过这些功能模块的实现，系统基本形成了较为完整的电子商务业务闭环。

## **2.1 Spring Boot框架**

Spring Boot 是建立在 Spring
生态之上的快速开发框架，能够通过自动配置、起步依赖和嵌入式容器简化传统Spring项目的环境搭建和模块集成过程。对于电商系统这类业务模块多、接口数量大、扩展频繁的项目而言，Spring
Boot 有利于在统一规范下组织控制层、业务层和数据访问层，提升开发效率。

在本系统中，Spring Boot 主要承担后端服务搭建、RESTful
接口发布、参数校验、统一异常处理、事务管理和安全框架集成等职责。结合分层架构后，控制层负责接收前端请求与返回统一结果，业务层处理订单、购物车和权限等核心逻辑，数据层负责与MySQL交互，从而实现较好的解耦性和可维护性。

## **2.2 Vue.js与Element UI**

Vue.js
是一种渐进式前端框架，具有组件化开发、双向数据绑定和虚拟DOM等优势，适合构建交互性较强的单页应用。商城类系统中，首页推荐、分类筛选、购物车状态同步和订单列表更新等场景对页面响应速度和组件复用性要求较高，Vue
能够较好满足这些需求。

本系统前端采用 Vue、Vue Router、Axios 与 Element UI 共同实现。Vue Router
用于组织前台页面和后台管理页面的路由，Axios 负责与后端API通信，Element
UI
提供表单、表格、分页、对话框等常用组件，从而提升界面开发效率和交互一致性。对于后台系统，还通过动态路由与权限指令实现菜单按角色加载、按钮按权限显隐。

## **2.3 MySQL与MyBatis-Plus**

MySQL
是成熟的关系型数据库，支持事务、一致性保障和复杂查询，适用于用户、商品、订单等结构化数据的存储。电商系统涉及大量实体之间的关联，如用户与地址、商品与分类、订单与订单项等，使用关系数据库有利于维护数据完整性与业务可追溯性。

MyBatis-Plus 在保留 MyBatis
灵活SQL能力的同时，进一步简化了常见CRUD操作的编写。对于本系统中的商品管理、用户管理、订单查询等场景，可以利用其基础方法快速开发；对于复杂统计和条件筛选，则可通过自定义
SQL 完成。配合 Spring
的事务机制，能够保证下单、扣库存和清购物车等操作的原子性。

## **2.4 JWT与RBAC权限控制**

JWT 是一种基于 JSON
的轻量级令牌机制，适合前后端分离项目下的身份认证场景。用户登录成功后，服务器将包含用户身份和角色信息的
Token 返回给前端，前端在后续请求中将 Token
放入请求头，服务端通过过滤器或安全框架解析 Token 并完成身份校验。

RBAC（Role-Based Access
Control）即基于角色的访问控制。本文将其应用于后台管理系统中，通过
user、role、menu、role_menu
等表构建权限模型，实现菜单权限和按钮权限双层控制。系统登录后返回 menus
与
perms，前端据此生成侧边栏并控制操作按钮显示，后端再进行接口级二次校验，以提升安全性与可管理性。

## **2.5 Redis/Nginx/Docker**

Redis
是高性能的内存数据库，常用于缓存热点数据、降低数据库压力。在本系统中，首页推荐商品、轮播图和部分商品详情适合作为缓存对象，通过
Cache-Aside 模式可以减少重复查询带来的性能开销。

Nginx 可用于前端静态资源托管、反向代理和统一入口转发；Docker 则有利于对
MySQL、Redis、后端服务和前端项目进行容器化部署。虽然本课题以教学实现为主，但在架构设计中预留了容器化部署能力，可为后续系统上线与扩展提供支持。
